# Closet by MP

A closet that builds itself: one mirror photo a day, and the app finds each piece of clothing, works out whether it has seen it before, and keeps track of what I actually wear.

**Status:** coming soon. **Page:** https://closet.marcantoniopovolo.com

The full build plan is in [SPEC.md](SPEC.md). Hard rules: it costs nothing, photos never leave the device, faces are never stored, and no typing is required.

Built by [Marcantonio Povolo](https://marcantoniopovolo.com). I decide what it does and review and test each change; AI coding tools help write the code.
